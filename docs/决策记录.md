## 0001 · 2026-10-28 · 仓库根移到 `本体\`，Git 只管代码

**背景**

汐的东西分在 `人格\`、`记忆\`、`本体\`。原先 `本体\dsh-xi-repo` 是个仓库副本，真正在跑的却是
`本体\dsh-xi` 和 `本体\xi-qq`——两份代码，8 个文件（0.7.1 人格/记忆分家）和 5 个调试脚本只在跑的那份里。
那时 `git checkout` 退的是仓库，跑的不动，等于没存档。

**决定**

1. 仓库根 = `E:\Ai-Agent\汐\本体`。`dsh-xi\`、`xi-qq\` 直接在根下，仓库里就是正在跑的代码。
2. 一次功能一个 commit，验证过再提交；发版打 tag（从 `v0.7.1` 起）。
3. 拉取只用 `git pull --ff-only`。合不了就停，先问，**不自动 merge**。
4. 图片、音频、视频不进 Git；`qq\`、`日志\`、`node_modules`、`_备份` 也不进。
5. 插件加载路径不变：`~/.dsh/plugins/dsh-xi` → `本体\dsh-xi`，`~/.dsh/xi-qq` → `本体\qq`。

**代价**

- `dsh-xi-qq/` 改名成 `xi-qq/`，这个 commit 里同时有移动和功能改动，早期 diff 要靠 `git log -M` 才看清。
- 拉取不再"自动合并"，冲突得人看一眼——这是故意的，自动 merge 会合出「干净但一跑就挂」的结果。
- `*.png` 一律忽略，以后界面要用的图得放 `素材\` 或改成 SVG。

**怎么退**

| 场景 | 命令 | 之后 |
|---|---|---|
| 退回某个版本 | `git switch --detach v0.7.0` | 重启 DSH，刷新页面 |
| 撤销最近一次提交，改动留在工作区 | `git reset --soft HEAD~1` | 不用重启，代码没变 |
| 撤销某次提交但留历史 | `git revert <sha>` | 重启 DSH |
| 对齐远端最新 | `git fetch origin && git reset --hard origin/main` | 重启 DSH（本地改动先 commit 或 stash） |

重启 = 关掉 DSH 再打开（`DeepSeek Harness.exe`），不是只刷新页面：`lib\*.js` 由宿主进程加载，
`client.js` 由页面加载，两边都要重来。

**新功能怎么走**

`git switch -c feat/xxx` → 改 → 重启验证 → 让阿晚确认 → `git switch main && git merge --ff-only feat/xxx` → 打 tag → 推。
