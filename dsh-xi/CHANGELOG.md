# CHANGELOG

## 0.6.0 · 2026-10-27
- NapCat 次级页扩成配置面板：私聊、群聊、总量、说话方式四段。
- 私聊：开关 + 每小时上限 + 最小间隔。
- 群聊：总开关 + 被 @ 的频率 + 没 @ 时主动接话的频率（含触发概率）。
- 总量：每日回复上限（所有通道合计，过零点重置），并显示今日已回条数。
- 说话方式：分条发 / 最多几条 / 显示正在输入 / 会话开头带风格说明。
- 宿主接口 `/api/dsh-xi/channel` 支持 `patch` 深合并；配置拆到 `lib/qqconfig.js`，`state.js` 与 `qqlink.js` 共用，避免循环依赖。
- 数字输入框去掉原生上下箭头。

## 0.5.0 · 2026-10-27
- 接入页的 QQ 改成入口卡片：只显示连接状态、账号、会话、NapCat 是否在跑，整张卡片可点（也支持键盘 Enter / 空格）。
- 新增 NapCat 次级页（`← 返回` 可退回）：桥状态、账号、启动 NapCat 按钮、两个开关、WebUI / 协议端 / 日志 / ws 地址。
- 两个开关从接入页移进次级页。

## 0.4.2 · 2026-10-27
- 开关配色跟宿主的 `color-scheme` 走（`light-dark()`）：浅色仍是黑描边，深色自动换成浅描边。
- 深色下轨道底色 `#f5f5f7`、开启蓝 `#3b82f6`，状态字 `#7aa7ff`；阴影加深一档，免得贴底看不见。
- 修掉「深色主题下黑边等于没边」的问题。

## 0.4.1 · 2026-10-27
- 开关换成左右滑动样式：关=白轨黑边、滑块在左；开=蓝轨（#2563eb）黑边、滑块在右。
- 轨道与滑块都加了黑色描边和阴影，和背景分开；滑动用 `cubic-bezier(.34,1.42,.64,1)`，按下去滑块会缩一下。
- 开关右侧显示 `（已启动）/（已关闭）`，切换时有一次淡入上浮动画。
- 点击后先本地翻状态再等宿主确认，不用等接口回来才动。

## 0.4.0 · 2026-10-27
- QQ 通道接上了：`extensions/qq` 从 planned 变 ready，承载插件是 `dsh-xi-qq`。
- 「接入」页新增 QQ 卡片：连接状态、账号、会话数、NapCat 是否在跑。
- 两个开关：**启用 QQ 通道**、**NapCat 自启动**。开关写 `~/.dsh/xi-qq/settings.json`，桥每 2 秒看一次 mtime，改完即时生效，不用重启。
- NapCat 没在跑时，卡片上给一个「启动 NapCat」按钮（会提权，弹一次 UAC）。
- 新增宿主接口 `POST /api/dsh-xi/channel`（`{id:'qq', enabled?, autostart?, action?:'start-napcat'}`）。
- 自启动打开时：DSH 起来 3 秒后检查一次，之后每 5 分钟检查一次，NapCat 掉了就补点火。

## 0.3.0 · 2026-10-27
- 人物格式化：插件不自带人设，首次加载引导用户设定名字 / 性别 / 称呼 / 人设。
- 留空项随机生成（六种初始性格）。
- 数据目录默认 `~/.dsh/xi/`；已存在 `~/.dsh/memory/SOUL.md` 时沿用旧目录，绝不覆盖。
- 初始化只创建缺失文件；已有 SOUL.md 时接口返回 409，不再写入。
- 新增宿主接口 `POST /api/dsh-xi/init`。

## 0.2.0 · 2026-10-27
- 左侧边栏新增「汐」入口，点击打开 `main` 主页面板。
- 数据源改为两个：先试宿主接口，失败自动退到本机控制台。
- 控制台服务端补 CORS。

## 0.1.0 · 2026-10-27
- 第一个版本：对话页「汐」标签，七个面板。
- 宿主半侧注册只读接口 `POST /api/dsh-xi/state`。
- 迁移模块 `lib/upgrade.js`，数据与代码分离。
- `extensions/` 预留 bilibili、qq、avatar、voice。
